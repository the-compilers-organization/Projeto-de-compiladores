# Testes da análise semântica

28 programas de teste para declaração, tipos, operações e comandos. Os arquivos `01` a `06`, `22`, `24`, `26` e `27` devem ser aceitos; os demais devem ser rejeitados.

Execute a partir de `micropascal-compiler/`: `sh rodar_testes_semanticos.sh` (Linux/macOS) ou `rodar_testes_semanticos.bat` (Windows).
